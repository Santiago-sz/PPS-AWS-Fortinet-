# Propuestas de modificación del informe

No hay propuestas de texto aprobadas ni cargadas en Google Docs al 2026-11-21.
Los hallazgos preliminares se guardan en [contexto](../contexto.md).

Crear una ficha `P-001-tema.md`, seguida de identificadores correlativos, por
incremento revisable. Usar estos campos:

| Campo | Contenido |
|---|---|
| Identificador y versión | P-001, v1; fecha de preparación |
| Estado | Borrador, presentada, en corrección, aprobada, aplicada y verificada, o descartada |
| Destino | Capítulo, sección, pestaña y ubicación del documento |
| Lectura de referencia | Fecha y revisión del documento cuando esté disponible |
| Problema | Contradicción, omisión, requisito o mejora concreta |
| Acción | Sustituir, añadir, mover o corregir formato |
| Texto propuesto | Contenido completo que el autor podrá revisar |
| Fundamento | Requisito, fuentes y evidencia del proyecto |
| Dependencias | Datos faltantes y otras secciones afectadas |
| Aprobación | Fecha, versión exacta y alcance expresamente aprobado; pendiente por defecto |
| Aplicación | Fecha y destino; verificación del resultado y límites |

Presentar el contenido de la ficha al autor. Guardarlo localmente no equivale a
presentarlo, aprobarlo ni cargarlo. Si cambia el documento antes de la carga,
comparar la sección de destino y resolver conflictos sin sobrescribir trabajo
ajeno. Actualizar el [registro](../registro.md) tras cada transición relevante.
